# Tick Talk Marketing

Static marketing site for Tick Talk.

## Local preview

Open `index.html` in a browser, or run a local static server from this directory:

```bash
python3 -m http.server 4176
```

Then visit `http://localhost:4176`.

## Pages

- `index.html`
- `privacy.html`
- `terms.html`

## Assets

The logo, app icon, and onboarding artwork were copied from the Tick Talk app build.
The app screenshot lives at `assets/app-screenshot.png`.
